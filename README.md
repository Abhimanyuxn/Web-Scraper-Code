# Web Scraper for Data Extraction

## Overview
This project is a Python-based web scraper that extracts real-time data (news headlines) from a website and stores it in a structured format. It demonstrates skills in web scraping, HTML parsing, and data handling.

---

## Features
- Extracts top headlines from a live website
- Parses HTML using BeautifulSoup
- Displays results in terminal
- Saves extracted data into a text file

---

## Tech Stack
- Python
- requests
- BeautifulSoup (bs4)

---

## How It Works
- Sends HTTP request to the target website
- Parses HTML content
- Extracts required data using tags and classes
- Stores output in a readable format
